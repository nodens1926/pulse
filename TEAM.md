**Направление:** Программная инженерия  
**Методология:** Scrum, спринты по 2 недели  
**Таск-трекер:** GitHub Projects

## Принципы работы

1. **Все участники пишут код.** Роли CEO и Designer не освобождают от участия в разработке.
2. **Scrum, спринты по 2 недели.** Планирование → разработка → ревью → демо.
3. **Работа через Pull Request.** Ветка `main` защищена, минимум 2 аппрува для мержа.
4. **Коммиты по стандарту** (Conventional Commits).
5. **Код-ревью обязателен** для всех изменений в `main`.
6. **Еженедельные синки** для синхронизации прогресса и блокеров.
7. **Sprint Review** раз в 2 недели с демо работающего функционала.
